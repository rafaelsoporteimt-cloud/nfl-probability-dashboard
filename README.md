# NFL Probability Engine - Dashboard

Aplicacion Streamlit creada a partir de los CSV exportados del modelo. No muestra datos en vivo.

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicar gratis en Streamlit Community Cloud

1. Crea un repositorio de GitHub (preferentemente privado si no deseas compartir datos).
2. Sube `app.py`, `requirements.txt` y toda la carpeta `data/`.
3. Ingresa a https://share.streamlit.io/ e inicia sesion con GitHub.
4. Selecciona Create app, el repositorio y el archivo principal `app.py`.
5. Publica la app. El servicio gratuito puede tener limites o entrar en reposo.

Nota: los datos reflejan el corte del archivo que se importo, no la situacion actual de la NFL.
